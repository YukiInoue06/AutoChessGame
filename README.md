# AUTO CHESS ARENA

チェス盤の上で 5 対 5 のユニットが自動で戦う、1人プレイのオートチェス（オートバトラー）です。
チェスのコマ6種・RPGのジョブ14種・獣3種・魔族3種、**全26種類**から編成を組みます。
モデルはすべて 3D — チェスのコマは回転体、ジョブはローポリゴンで作っています。
ユニットごとに識別色があり、陣営（味方=明るい / 敵=暗い）を保ったまま種類を見分けられます。

> AIのみで作成。

## 遊びかた

```bash
npm start      # http://localhost:5173 が開けるようになります
```

ビルド不要・依存パッケージのインストール不要です（Three.js は `vendor/` に同梱）。
ES モジュールを使うので `file://` では動きません。上のコマンド（またはお好みの静的サーバ）経由で開いてください。

ポートを変えたいときは `PORT=8080 npm start`。

## ゲームの流れ

0. **定跡** — ランの最初と、R6 / R12 / R18 の区切りで、3つの候補から1つ選ぶ（積み上がる）
1. **ショップ** — 5枠の品揃えからユニットを雇う。リロール・経験値購入・売却もここ
2. **準備フェーズ** — 手前3列にドラッグして配置。**盤に出せるのはレベルと同じ人数**
3. **特性** — 盤に並べた顔ぶれで **組み合わせバフ** が発動する（左のパネルで確認）
4. **バトル** — 自動で戦闘。相手を全滅させれば勝ち
5. **成長** — 収入と経験値が入る。負けるとライフが1減り、0でゲームオーバー

ラウンドは無限に続きます。どこまで勝ち進めるかに挑戦してください（自己ベストはブラウザに保存されます）。

## ショップとレベル

Teamfight Tactics と同じ考え方です。**ゴールドで雇い、レベルで出せる人数が決まり、
同じユニットを3体そろえると★が上がります**。ユニットのコストは買値であり、
盤の上では1体は1体として数えます。

| 要素 | 内容 |
| --- | --- |
| 開始ゴールド | 12G |
| 収入 | ラウンドごとに 基本10G ＋ 勝利4G ＋ 連勝ボーナス（最大5G） |
| 雇用コスト | ユニットごとに1〜5G |
| ショップ | 5枠。ラウンドごとに無料で更新、2Gでリロール |
| 予約 | 枠の左上の 📍 を押すと、その枠だけリロールとラウンド跨ぎで残る（1枠のみ） |
| レベル | 3から8。**盤に出せる人数＝レベル** |
| 経験値 | ラウンドごとに自動で+2。4Gで+4exp 購入できる |
| 必要経験値 | Lv4:6 / Lv5:10 / Lv6:20 / Lv7:36 / Lv8:56 |
| ★アップ | 同じユニットが3体そろうと自動で合成。★2が3体で★3 |
| 売却 | ★1は雇用コスト、★2は3倍、★3は9倍（コスト2以上は1G差し引き） |
| 控え | 8枠。買ったユニットはここに入り、盤に空きがあれば自動で出撃します |

### レアリティ

ユニットには **コモン / アンコモン / レア / エピック / レジェンド** の5段階のレアリティがあります。
ショップの抽選確率はこのレアリティで決まり、カードの縁とレアリティ名の色もこれに合わせています。

| レアリティ | 色 | 種類数 | 雇用コスト |
| --- | --- | --: | --: |
| コモン | 灰 | 1 | 1G |
| アンコモン | 緑 | 6 | 2G |
| レア | 青 | 9 | 3G |
| エピック | 紫 | 7 | 4G |
| レジェンド | 金 | 3 | 5G |

レアリティは「どれだけ出やすいか」、コストは「いくらで雇えるか」で、別々の項目として持っています
（いまはたまたま一致していますが、片方だけ変えることもできます）。
カードの **縁の色がレアリティ**、内側の細い帯と絵柄の色が **ユニットの識別色** です。

### ショップの抽選確率

レベルが上がると上位のレアリティが出やすくなります。レジェンドはレベル7から。

| Lv | コモン | アンコモン | レア | エピック | レジェンド |
| --: | --: | --: | --: | --: | --: |
| 3 | 75% | 25% | — | — | — |
| 4 | 55% | 30% | 15% | — | — |
| 5 | 45% | 33% | 20% | 2% | — |
| 6 | 25% | 40% | 30% | 5% | — |
| 7 | 19% | 30% | 35% | 15% | 1% |
| 8 | 15% | 25% | 32% | 22% | 6% |

「レベルを上げて人数と上位レアリティを狙う」か「ゴールドをリロールに使って★3を狙う」かが
毎ラウンドの判断になります。敵の人数もこちらのレベルに合わせて増えます。

**予約** は、いま欲しいけれどゴールドが足りないユニットを次のラウンドまで取っておく仕掛けです。
リロールしても無料更新でも消えません。予約できるのは1枠だけで、別の枠を押すと予約はそちらへ移ります。
予約した枠を買うと、予約はそこで解除されます。

**控え（ベンチ）** は盤の手前にぶら下がっている列です。ここに置いたユニットは戦闘に参加しませんが、
★アップの合成には数えられます。準備フェーズ中にドラッグで盤と行き来できます。

## 定跡

ラン開始時と、**ラウンド1 / 6 / 12 / 18** の区切りで、12種のうちランダムな3つから1つ選びます。
選んだものは **積み上がって** ラン中ずっと効き続け、途中で捨てることはできません。
候補は **ラン全体で2回まで引き直せます**（一度取った定跡は候補に出ません）。
ヘッダーに出ている定跡名を押すと、いま効いているものを一覧で見返せます。

候補は既定でたたまれていて、**タップすると説明と効果が開きます**。開いてから
「この定跡にする」を押して決定します。選ぶ画面の上には **いまの編成と発動中の特性** が
並ぶので、手持ちに噛み合うものを選べます。

| 定跡 | 効果 |
| --- | --- |
| **シチリア防御** | ライフ +2 ／ 毎ラウンドの収入 -1G |
| **クイーンズ・ギャンビット** | ゴールド +16 ／ 毎ラウンドの収入 -1G |
| **ルイ・ロペス** | ビショップ1体 ／ 「術士」を1種多く数える |
| **キングズ・インディアン** | レベル +1（出せる人数 +1）／ ゴールド -3 |
| **イタリアン・ゲーム** | リロール -1G ／ 勝利ボーナス +2G |
| **アレヒン防御** | ナイト1体 ／ 「速攻」を1種多く数える ／ 毎ラウンドの経験値 +1 |
| **ポーンストーム** | ポーン1体 ／ 「チェス」を1種多く数える |
| **フィアンケット** | 「支援」を1種多く数える ／ 毎ラウンドの収入 +1G |
| **ルーク・リフト** | ルーク1体 ／ 「重装」を1種多く数える |
| **オープンファイル** | 「射手」を1種多く数える ／ 勝利ボーナス +2G |
| **ツークツワンク** | 相手の強さ -6% |
| **プロモーション** | ショップの枠 +1（6枠） |

効果は種類ごとに合算されます。リロール代や収入のような数値は足し算、
特性の下駄は特性ごとに足し算です（同じ特性に2つ乗れば +2種）。

「種類数を1つ多く数える」定跡は、**そのユニットが盤に1体もいなくても1種として数えます**。
つまりルイ・ロペスなら、術士のユニットを1種そろえるだけで術士2が発動します。
この下駄がかかるのは自分だけで、相手には乗りません。

自動プレイ30回で測ると、区切りごとに定跡を積んだ場合の到達ラウンドは
定跡なしより **約1ラウンド長い** 程度でした（botは候補をランダムに選ぶので、
噛み合わせを狙えばもっと伸びます）。

## 特性（組み合わせバフ）

ユニットにはそれぞれ **出自** と **職能** の特性が1つずつ付いています。
盤に出したユニットの **種類数** が条件に達すると、その特性のバフがかかります。
同じユニットを何体並べても種類数は1です（★アップは種類数に影響しません）。

左のパネルに現在の状況が出ます（縦画面では盤の上に横並びのチップ）。
発動中は明るく、未達のものは「あと◯種で発動」と表示されます。
**敵にも同じルールでバフがかかります** — 相手の編成が揃っているほど手強くなります。

**特性名をクリックすると全段階の効果が出ます。** 特性パネル・ショップのカード・
コマの詳細、どの特性チップからでも同じものが開きます。その特性を持つユニットの一覧も出て、
いま盤に出ているものは固有色、そうでないものは灰色で表示されます。

## 戦闘のしくみ

- 各ユニットは **いちばん近い敵** を狙い、自分の移動パターンで1手ずつ近づきます
  （チェスのコマは本家どおり、ジョブは役割に合わせた動き）
- 射程内に入ると自動で攻撃。攻撃と被弾で **マナ** が溜まります
- マナが満タンになると **スキル** を発動（足元のリングが金色に光ります）
- 物理ダメージは防御、魔法ダメージは魔法防御で軽減
  （軽減率 = `100 / (100 + 防御値)`）
- 40秒で **サドンデス**。全ユニットが毎秒じわじわ削られ、決着がつきます
- 一部のスキルには **行動不能**・**攻撃速度低下**・**召喚** などの効果があります

### 色の見分け方

26種類が並ぶと形だけでは判別しづらいので、ユニットごとに固有色を割り当てています。

- **本体** … 陣営の地の色（味方は明るい／敵は暗い）を固有色へ寄せた色。明暗で陣営がわかります
- **差し色** … 固有色そのもの。兜・武器・装飾に出ます
- **足元のリング** … 陣営色（味方=水色 / 敵=赤）とマナ満タン（金）の表示。ここは種類では変わりません

チェスのコマは差し色の面積が小さいので、根元に固有色のリングを1本巻いています。
兵舎のカードにも同じ色が出るので、盤の上のコマと対応が取れます。

## 構成

```
index.html            エントリ（importmap で three を解決）
src/
  main.js             全体の配線とゲームループ
  core/
    units.js          全26種の定義（ステータス・移動パターン・スキル・特性・レアリティ）
    traits.js         特性（組み合わせバフ）の定義と、条件判定・補正の適用
    openings.js       定跡の定義と、候補の抽選
    board.js          8x8 盤のロジックと、チェス移動に基づく経路探索
    battle.js         オートバトルのシミュレーション（描画非依存）
    game.js           ラウンド進行・敵編成・経済（ゴールド/レベル/ショップ/控え）・セーブ
  render/
    scene.js          レンダラ / カメラ / ライト / 盤
    pieces.js         3Dモデル生成（チェス=回転体 / ジョブ・魔族=ローポリ人型 / 獣=四足）
    unitView.js       1体ぶんの見た目（HP/マナバー・移動や被弾の演出）
    effects.js        弾・ダメージ数値・衝撃波などのエフェクト
  input/placement.js  ドラッグ配置とコマ選択
  ui/hud.js           DOM の UI（ヘッダー・ログ・各種オーバーレイ）
scripts/serve.js      依存なしの静的サーバ
vendor/three/         Three.js r185（MIT）
```

戦闘ロジック（`core/`）は描画をまったく参照しません。
`BattleEngine` は起きた出来事を `onEvent(type, payload)` で外へ流し、
`main.js` がそれを 3D の演出と UI に翻訳しています。
